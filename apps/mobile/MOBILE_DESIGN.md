# Mobile Design System - PRETOS MUSIC

## 🎨 Sistema de Design

### Cores

**Primary (Indigo)**
- Principal: `#6366F1`
- Dark: `#4F46E5`
- Light: `#818CF8`

**Secondary (Pink)**
- Principal: `#EC4899`
- Dark: `#DB2777`
- Light: `#F472B6`

**Backgrounds**
- Background: `#FFFFFF`
- Secondary: `#F8FAFC`
- Tertiary: `#F1F5F9`

### Typography

- **H1**: 32px, weight 800, line-height 40
- **H2**: 24px, weight 700, line-height 32
- **H3**: 20px, weight 600, line-height 28
- **Body**: 16px, weight 400, line-height 24
- **Caption**: 12px, weight 400, line-height 16

### Spacing

- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px
- xl: 32px
- xxl: 48px

### Border Radius

- sm: 8px
- md: 12px
- lg: 16px
- xl: 24px
- full: 9999px

## 📱 Screens Implementadas

### HomeScreen
- Header com saudação
- Seção de Singles em Produção (últimos 3)
- Seção de Próximos Eventos (últimos 3)
- Pull-to-refresh
- Design moderno com cards elevados

### SinglesScreen
- Lista completa de singles
- Cards modernos com gradiente
- Header informativo
- Pull-to-refresh
- Empty state

### EventsScreen
- Lista completa de eventos
- Cards modernos
- Header informativo
- Pull-to-refresh
- Empty state

### ProgressCard Component
- Header com cor primária
- Badge de progresso
- Barra de progresso animada
- Footer com data (se disponível)
- Design moderno e elegante

## 🎯 Componentes UI

### Card
- Variantes: default, elevated, outlined
- Padding configurável
- Sombras suaves

### Button
- Variantes: primary, secondary, outline, ghost
- Tamanhos: small, medium, large
- Loading state
- Disabled state
